# AirVT-15k GitHub Pages Downloads

This directory contains files exposed by the AirVT-15k project page.

## Included

- `evaluation/evaluate_retrieval.py`: official retrieval metric script.
- `evaluation/sample_t2v_submission.jsonl`: text-to-video prediction format example.
- `evaluation/sample_v2t_submission.jsonl`: video-to-text prediction format example.
- `splits/train.txt`, `splits/val.txt`, `splits/test.txt`: official split ids.
- `split_summary.json`: split statistics.

## Not Included

The complete videos, annotations, and `metadata/captions.jsonl` should be distributed through the official dataset release channel.
