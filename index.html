Low-altitude UAV Video-Text Retrieval Benchmark

AirVT-15k

A multi-scenario, application-oriented, event-diverse benchmark for text-video retrieval in low-altitude UAV videos.

View Examples Benchmark Protocol Resources

Dataset Overview

Existing text-video retrieval benchmarks are mainly built on general videos, while low-altitude UAV videos introduce overhead viewpoints, small objects, weak motion, redundant backgrounds, scene homogeneity, and domain-specific application semantics. AirVT-15k is designed to evaluate retrieval models under these low-altitude challenges.

15,573low-altitude UAV videos
155,730video-text caption pairs
10caption pairs per video
2-waytext-to-video and video-to-text retrieval

Coverage Design

AirVT-15k organizes low-altitude videos with three complementary design principles. Scenarios define the visual environment, applications define practical retrieval needs, and events define the video semantics.

Multi-scenario Coverage

Typical low-altitude visual environments with different backgrounds, targets, layouts, and event patterns.

AirportPortRoadRailwayWaterUrbanIndustrialDisaster

Application-oriented Design

Scene and caption organization aligned with real low-altitude use cases.

Urban InspectionTraffic RetrievalPort MonitoringRailway InspectionWater PatrolDisaster ResponseConstruction Analysis

Diverse Event Semantics

Events in UAV videos often appear as subtle state, direction, density, and region changes.

Annotation Format

Each annotation contains video metadata, scene category, application task, event semantics, low-altitude characteristics, and ten English-Chinese caption pairs. A full sample is available at samples/annotation_sample.json. 

{
  "video_id": "015614",
  "video": "videos/015614.mp4",
  "scene": {
    "category": "road",
    "name": "night urban intersection"
  },
  "application": {
    "task": "traffic_retrieval",
    "description": "retrieving dense traffic and pedestrian activity from low-altitude UAV videos"
  },
  "events": [
    "vehicle_movement",
    "pedestrian_gathering",
    "traffic_density"
  ],
  "low_altitude_characteristics": [
    "overhead_viewpoint",
    "small_targets",
    "background_redundancy"
  ],
  "captions": [
    {
      "english": "Dense nighttime traffic and pedestrians gather around a bright urban intersection.",
      "chinese": "夜间明亮的城市路口周围聚集了密集车流和行人。"
    },
    {
      "english": "Small vehicles move around crowded sidewalks and a complex road layout.",
      "chinese": "小型车辆在拥挤人行道和复杂道路结构周围移动。"
    },
    ...
  ]
}

Benchmark Protocol

The benchmark evaluates bidirectional retrieval with R@1, R@5, R@10, and mR. Here mR denotes the mean of R@1, R@5, and R@10.
